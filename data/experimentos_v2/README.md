# Experimentos CAMELS-PE V2

Este directorio contiene la segunda corrida reproducible y aislada de la
evaluación regionalizada CAMELS-PE. Los artefactos V1 bajo
`data/experimentos/` no se modifican.

La ventana efectiva es 1981-01-01 a 2016-12-31. La configuración de cada
corrida, el entorno y su estado se almacenan sin sobrescritura en `runs/`.
